# trainingms Documentation

This folder contains organized, useful documentation for developers working on the NOM-035 trainingms platform.

- deployment/ — Server setup and ops (Forge, Horizon)
- reports/pdf/ — PDF reports implementation, fixes, and templates
- dashboard/ — Dashboard report migration and summaries
- paper-evaluation/ — Backend storage, jobs, and migration guides for paper evaluations
- frontend/
  - results/ — Frontend results UI and migrations
  - notifications/ — Persistent notifications system
  - quiz/ — Quiz UX and small frontend guides
- optimization/ — Performance optimization guides
- omr/ — OMR (Optical Mark Recognition) calibration and templates
- config/ — Configuration migration and references
